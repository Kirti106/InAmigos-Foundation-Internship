# 🌟 InAmigos Foundation Awareness Webpage

A simple and responsive NGO awareness webpage created using HTML and CSS to spread awareness about the initiatives and social impact of the InAmigos Foundation.

---

## 📌 Project Objective

The objective of this project is to design and develop a basic awareness webpage for an NGO that highlights:

- NGO introduction
- Ongoing projects and initiatives
- Social impact
- Volunteer and donation opportunities
- Contact information

This project was created as part of an internship/task assignment.

---

## 🏢 About InAmigos Foundation

InAmigos Foundation is a Section 8 registered non-profit organization founded in 2020 by Mr. Govind Shukla. The organization works towards:

- Education
- Women empowerment
- Environmental sustainability
- Animal welfare
- Food distribution
- Social inclusion programs
